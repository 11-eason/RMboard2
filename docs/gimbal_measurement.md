# 云台装配后需要实测的量与测量方法

> 用途：裸电机跟随调通之后，装上云台结构需要重新确定的参数。
> 这些数据填进 `applications/control_constants.hpp` 的 `FOLLOW_*` 参数即可，代码不需要改。

## 为什么必须重测

裸电机阶段所有前馈都可以关掉：

| 项目 | 裸电机近似值 | 说明 |
| --- | --- | --- |
| 转动惯量 | ~1.3×10⁻⁴ kg·m² | 10⁻⁴ 量级 |
| 曲线峰值加速度 106.85 rad/s² 所需力矩 | J·α ≈ 0.014 N·m | 仅为限幅的 4%，可忽略 |
| 启动摩擦 | ≈ 0.07 N·m（0.1 A 才转） | 比惯性力矩大 5 倍，由速度环积分吸收 |

加上云台结构后，惯量可能增大 5~50 倍、pitch 轴出现重力矩、还要考虑机械行程与柔性，
所以**加速度前馈、重力前馈、限幅和增益都必须重算**。

## 测量清单一览

| # | 要测的量 | 填到哪个参数 | 优先级 |
| --- | --- | --- | --- |
| 1 | yaw 轴转动惯量 J_yaw | `FOLLOW_YAW_ACCEL_FF_J` | 必须 |
| 2 | pitch 轴转动惯量 J_pitch | `FOLLOW_PITCH_ACCEL_FF_J` | 必须 |
| 3 | pitch 重力矩系数 K_g = m·g·r | `FOLLOW_PITCH_GRAVITY_NM` | 必须（有偏置质量时） |
| 4 | 静摩擦/启动电流（两轴、两方向） | 限幅与积分上限的校核 | 必须 |
| 5 | 机械行程（两轴） | `FOLLOW_*_ANGLE_MIN/MAX_RAD` | 必须 |
| 6 | 柔性/共振（可选） | 外环增益上限 | 建议 |

## 1. yaw 轴转动惯量 J_yaw

**方法：电流阶跃法（轴自由、无重力分量）**

1. 把 yaw 轴悬空，确认可自由转动、线缆有余量；
2. 把 `FOLLOW_CONSTANT_TORQUE_TEST` 设为 `true`，`FOLLOW_TEST_TORQUE_NM` 设 0.20 N·m；
3. 烧录后电机以恒定力矩加速，用绘图/串口记录**转速**随时间的变化；
4. 取加速段的斜率：`α = Δω / Δt`（单位 rad/s²）；
5. 计算：

```
J = 力矩 / α        （力矩单位 N·m，α 单位 rad/s²，结果 kg·m²）
```

6. 反向再测一次（力矩取 −0.20 N·m），两次结果取平均以抵消摩擦。

**注意**：必须在**转速较低**的区段取斜率（避免反电动势/控制饱和影响）；
若加速度很小（说明摩擦占主导），把测试力矩加大到 0.3 N·m 重测。

**典型量级参考**：小型二维云台 yaw 轴 1×10⁻³ ~ 1×10⁻² kg·m²。

## 2 & 3. pitch 轴：一次实验同时得到 J 和重力矩系数

**方法：摆动周期法（推荐）**

1. 把 `FOLLOW_CONSTANT_TORQUE_TEST` 与跟随都关掉（电机零输出）；
2. pitch 轴抬起 5°~10°，松手让它自由摆动；
3. 记录**摆动周期 T**（从一侧极点到下一次同侧极点的时间，或用秒表量 10 个周期除以 10）；
4. pitch 轴上的重力矩在小角度内近似线性：`τ ≈ K_g · θ`，其中 `K_g = m·g·r`；
5. 计算：

```
K_g = J_pitch · (2π / T)²          ← 需要 J_pitch
J_pitch = K_g / (2π / T)²          ← 需要 K_g
```

两个未知、一个方程，所以补充第二步（**静态保持法**）解出 K_g：

**静态保持法（求 K_g）**：
1. 让 pitch 轴停在 0°、±15°、±30° 各 5 s（用手扶住，记录维持不动所需的电流）；
2. 记录 `停住需要的力矩 = K_g · cos(θ) + 摩擦`；
3. 用最小二乘拟合 `τ(θ) = K_g·cos(θ) + τ_f` → 直接得到 `K_g` 和摩擦 `τ_f`；
4. 再把 K_g 代回摆动周期公式得到 J_pitch。

**简化做法**（够用）：只做静态保持法得到 K_g；J_pitch 用第 1 节的电流阶跃法
（把 pitch 轴水平放置，使重力矩为 0 时测）。

## 4. 静摩擦 / 启动电流

**方法：电流爬坡**

1. `FOLLOW_CONSTANT_TORQUE_TEST = true`，力矩从 0.02 N·m 开始，每次 +0.02 N·m；
2. 记录**开始连续转动**的力矩值（不是抖动，是连续转）；
3. 两个方向各做一次。

用途：
- 判断 `FOLLOW_*_MAX_TORQUE_NM` 是否足够（建议 ≥ 3 倍启动摩擦）；
- 判断速度环积分上限 `FOLLOW_*_SPEED_INTEGRAL_LIMIT` 是否足够（必须 > 启动摩擦）。

---

## 5. 机械行程

1. 断电，手动把两轴推到机械极限，记录角度（用绘图读当前角度，或用量角器）；
2. 两端各留 3°~5° 余量；
3. 填入 `FOLLOW_YAW_ANGLE_MIN_RAD` / `MAX_RAD`、`FOLLOW_PITCH_ANGLE_MIN_RAD` / `MAX_RAD`；
4. 同时把 `FOLLOW_ENFORCE_ANGLE_LIMITS` 设为 `true`。

⚠️ 轨迹本身是 yaw ±22.5°、pitch ±30°，若机械行程小于这个范围，必须先用
`FOLLOW_TRAJECTORY_TIME_SCALE` 之外的办法（改小 `TRAJECTORY_YAW_RANGE_DEG` /
`TRAJECTORY_PITCH_RANGE_DEG`）缩小幅度，否则会撞限位。

---

## 6. 柔性 / 共振（可选，但很有价值）

机械臂、同步带、长支架会引入柔性，使**某个频率**附近误差突然放大。

1. 在 `FOLLOW_TRAJECTORY_TIME_SCALE = 1` 下跑完整轨迹，记录误差曲线；
2. 若误差在轨迹的某一段（对应某个角速度峰值）异常大，说明接近共振；
3. 处理：降低位置环 `KP`、或在速度前馈上加低通、或提高结构刚性。

## 拿到数据后我会改哪些参数

| 参数 | 由数据直接算出 |
| --- | --- |
| `FOLLOW_*_ACCEL_FF_J` | 填入实测 J |
| `FOLLOW_PITCH_GRAVITY_NM` | 填入实测 K_g |
| `FOLLOW_*_MAX_TORQUE_NM` | ≥ J·α_max + K_g + 3×摩擦，且 ≤ 2.2 N·m（GM6020 上限） |
| `FOLLOW_*_SPEED_INTEGRAL_LIMIT` | ≥ 2×摩擦 |
| `FOLLOW_*_SPEED_KP` | ≤ J / (0.741 × 5 × 实际电流帧周期)，再用实测微调 |
| `FOLLOW_*_MAX_ACCEL_RAD_S2` | ≥ 轨迹峰值加速度 × 1.5 |
| `FOLLOW_*_MAX_SPEED_RAD_S` | ≥ 轨迹峰值角速度 × 1.5 |
